# Wiki Markdown 规范

Wiki 是正式字幕的事实来源。用户通常提供一个本地 UTF-8 `.md` 文件，Agent 原样保存为 `wiki-source.md`，无需抓取网页。

## 推荐结构

```markdown
# 教程标题

## 工具与准备

- H2.0 内六角扳手
- 关闭电源，等待热端冷却。

## 操作步骤

1. 移除一颗螺丝，小心取下背板。
2. 打开卡扣，移除热端。
3. 小心放入新热端，闭合卡扣。
4. 安装并锁紧螺丝。

## 配置分支：已安装 AMS

1. 移除背板前先断开 AMS 电缆。

> 注意：热端未冷却前不要触碰。
```

## 规则

- 时间线动作使用有序列表；
- 一个编号步骤保持一个主要动作目标；
- 明确写出部件、数量、规格、方向和警告；
- 工具、准备、安全提示放在独立小节，不自动视为拍摄步骤；
- 互斥机型或配置分支使用明确标题；
- 图片有价值时保留 alt 文本或画面说明；
- 避免“安装这个”“移除它”等缺少对象的表达；
- 不写没有事实依据的安全或营销结论。

Agent 可以调整语序、主语和连接词，但不得增加 Wiki 未支持的零件、数量、数值、操作、方向或安全结论。
