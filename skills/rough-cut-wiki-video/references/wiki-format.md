# 教程步骤输入规范

教程步骤是正式字幕的事实来源。用户可以直接在对话框粘贴普通文字，也可以提供 UTF-8 `.txt`、`.md` 或 Wiki 导出的文本文件。Agent 应把粘贴内容原样保存为任务目录中的 `wiki-source.md`，无需抓取网页。

## 推荐结构

```text
步骤一：移除固定螺丝，然后小心取下外壳，避免拉扯线缆。
步骤二：打开卡扣，垂直取出旧模块。
步骤三：对准位置轻轻放入新模块，然后闭合卡扣。
步骤四：装回并锁紧固定螺丝。
```

## 规则

- 只写实际拍摄、需要出现在时间线里的动作；
- 使用“步骤一、步骤二、步骤三”或 `1.`、`2.`、`3.` 按最终观看顺序叙述；
- 一个编号步骤保持一个主要动作目标；
- 把对象、数量、方向和必要提醒写进相关步骤；
- 不需要提供未拍摄的工具清单、准备工作、背景介绍、开场或原理说明；
- 多个操作分支只保留实际拍摄的分支，或分别明确标注；
- 避免“安装这个”“移除它”等缺少对象的表达；
- 不写没有事实依据的安全或营销结论。

Agent 可以调整语序、主语和连接词，但不得增加输入步骤未支持的对象、食材、零件、数量、数值、操作、方向或安全结论。
